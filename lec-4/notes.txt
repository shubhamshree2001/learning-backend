what are HTTP headers?
the metaadata which is sent --> key value which is sent in request and response

use of HTTP headers?
1. caching -> when the request comes, if we can use any data from the cache database
2. authentication -> beare token, session cookies, session values, refresh token, cookies
3. manage state -> state of user (guest user/ logged in user)

x-prefix is deprecated from headers after 2012 

Request headers -> from client
Response headers  -> from server
Representation headers -> encoding/compression [when to send large data]
Payload headers -> data


Most common Headers :
Accept : application/json' -> type of data which you accept
user-Agent --> it tells from which application request has come (postman, browser, safari)
authorization -> bearer token
content-type -> type of data like images/pdf 
cookie -> {key -value} pair for cookie details
cache-control -> after how much time we should expire the data

HTTP Methods (operations)
1. get -> to retrieve a resource
2. HEAD -> no message body (response header only) --> to see cache control , or user headers
3. OPTIONS -> what operations (get/put/post) are available at a endpoint
4. TRACE -> loopback test (get same data) --> some time resources are behind the proxy , so to check from all which proxy request is passing by, or coming by . to debug it is taking to much time , hopping time 
5. DELETE --> remove a resource
6. PUT --> replace the resource 
7. POST --> interact with resource (add the resource)
8. PATCH --> change the particular part in that resource
